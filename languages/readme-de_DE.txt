Generieren Sie automatisch SEO-optimierten Alt-Text, Titel und Bildunterschriften für Ihre Bilder mit KI-Technologie.

== Beschreibung ==

ForVoyez Automatischer Alt-Text für Bilder ist ein leistungsstarkes WordPress-Plugin, das KI-Technologie nutzt, um automatisch hochwertige, SEO-freundliche Alt-Texte, Titel und Bildunterschriften für Bilder in Ihrem Inhalt zu generieren. Dieses Plugin verbessert die Zugänglichkeit und Suchmaschinenoptimierung Ihrer Website mühelos.

= Hauptfunktionen =

* 🤖 KI-gestützte Alt-Text-Generierung
* 🖼️ Massenverarbeitung für bestehende Bilder
* 🔄 Automatische Verarbeitung für neue Uploads
* 🎨 Anpassbare Ausgabeformate
* 🌐 Mehrsprachige Unterstützung
* 🧰 Benutzerfreundliche WordPress-Admin-Oberfläche

Unsere KI-gestützte API erleichtert es Entwicklern und Content-Erstellern, Bilder für SEO zu optimieren. Sparen Sie Zeit, verbessern Sie SEO und optimieren Sie Ihren Workflow mit unserer leistungsstarken Lösung.

== Installation ==

1. Laden Sie die Plugin-Dateien in das Verzeichnis `/wp-content/plugins/auto-alt-text-for-images` hoch, oder installieren Sie das Plugin direkt über den WordPress-Plugins-Bildschirm.
2. Aktivieren Sie das Plugin über den Bildschirm 'Plugins' in WordPress.
3. Verwenden Sie den Bildschirm Einstellungen -> ForVoyez Auto Alt-Text, um das Plugin zu konfigurieren.
4. Geben Sie Ihren ForVoyez API-Schlüssel auf der Einstellungsseite ein.

= Einen API-Schlüssel erhalten =

1. Besuchen Sie die [ForVoyez Anmeldeseite](https://forvoyez.com/sign-up), um ein Konto zu erstellen.
2. Nach der Anmeldung navigieren Sie zu Ihrem [ForVoyez Dashboard](https://forvoyez.com/app).
3. Generieren Sie einen API-Schlüssel im API-Bereich Ihres Dashboards.
4. Kopieren Sie den API-Schlüssel und fügen Sie ihn in die Einstellungsseite des Plugins ein.

== Häufig gestellte Fragen ==

= Benötige ich einen API-Schlüssel, um dieses Plugin zu nutzen? =

Ja, Sie benötigen einen ForVoyez API-Schlüssel, um dieses Plugin zu nutzen. Sie können einen erhalten, indem Sie sich unter [https://forvoyez.com](https://forvoyez.com) registrieren.

= Kann ich den generierten Alt-Text anpassen? =

Während das Plugin automatisch Alt-Text generiert, können Sie den generierten Text für jedes Bild bei Bedarf manuell bearbeiten.

= Funktioniert dieses Plugin mit allen Bildformaten? =

Das Plugin funktioniert mit den gängigsten von WordPress unterstützten Bildformaten, einschließlich JPEG, PNG, GIF und WebP.

= Wird dieses Plugin meine Website verlangsamen? =

Nein, das Plugin verarbeitet Bilder im Hintergrund und beeinträchtigt nicht die Frontend-Leistung Ihrer Website.

= Wie funktioniert die Massenverarbeitungsfunktion? =

Sie können mehrere Bilder in Ihrer Medienbibliothek auswählen und die Option "Alt-Text generieren" aus dem Dropdown-Menü für Massenaktionen verwenden, um alle auf einmal zu verarbeiten.

= Ist der generierte Inhalt mehrsprachig? =

Die KI kann Inhalte in mehreren Sprachen generieren. Sie können Ihre bevorzugte Sprache in den Plugin-Einstellungen angeben.
